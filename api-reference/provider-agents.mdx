---
title: Provider agent mapping APIs
description: Map provider-side agent identifiers to Clawb agent IDs and query inventory metadata.
---

Use these APIs to maintain durable provider inventory metadata.

## POST `/v1/provider/agents/upsert`

Idempotently maps a provider-side key to a Clawb `agent_id` inside the provider workspace.

### Auth

Provider API key required.

```http
X-Clawb-Api-Key: ck_live_...
```

### Request body

```json
{
  "external_agent_key": "github:app:123",
  "agent_id": "agt_01jv2fsk4mv9mtr9j3m7h6qk6y",
  "display_name": "Payments assistant",
  "labels": ["prod", "payments"],
  "environment": "prod",
  "source": "provider_api",
  "status": "active"
}
```

### Python SDK example

```python
from clawb_agent_sdk import ClawbClient, ApiProvider

client = ClawbClient(base_url="https://api.clawb.ai/api")
provider = ApiProvider(client=client, api_key="ck_live_...")

# Upsert is safe to call repeatedly with the same mapping.
resp = provider.provider_agents_upsert(
    external_agent_key="github:app:123",
    agent_id="agt_01jv2fsk4mv9mtr9j3m7h6qk6y",
    display_name="Payments assistant",
    labels=["prod", "payments"],
    environment="prod",
    source="provider_api",
    status="active",
)
print(resp)
```

### Errors

- `401 {"error":"missing_api_key"}`
- `400 {"error":"missing_external_agent_key"|"missing_agent_id"|"invalid_labels"...}`
- `404 {"error":"unknown_agent"}`
- `409 {"error":"conflict"}` when key is already mapped to a different agent

## GET `/v1/provider/agents`

Lists mappings in the provider workspace.

### Query params

- `environment`
- `status`
- `label`

### Curl example

```bash
curl -sS "https://api.clawb.ai/api/v1/provider/agents?environment=prod&label=payments" \
  -H "X-Clawb-Api-Key: ck_live_..."
```

### Python SDK example

```python
# Filter by environment + label.
out = provider.provider_agents_list(environment="prod", label="payments")
print("count:", out.get("count"))
for mapping in out.get("mappings", []):
    print(mapping["external_agent_key"], "->", mapping["agent_id"])
```
