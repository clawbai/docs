Use this section when you need exact endpoint contracts.

These APIs are the interface to Clawb’s agent control plane for production systems.

## Base URL

Use:

```text
https://api.clawb.ai/api
```

All examples in this section assume that base URL.

## Authentication model

Clawb has three auth modes.

1. `Agent-signed requests` for agent-runtime endpoints.
2. `Workspace API key` for workspace control-plane and decision endpoints.
3. `Dashboard session auth` for dashboard-only APIs.

Most pages in this API reference focus on workspace APIs.

Workspace API key headers:

```http
# Preferred
X-Clawb-Api-Key: ck_live_...

# Alternative
Authorization: Bearer ck_live_...
```

## Error model

Most APIs return JSON with an `error` string on failure.

```json
{
  "error": "missing_api_key"
}
```

Some endpoints also return additional fields such as `retry_after`, `max_ttl_seconds`, `decision`, or `challenge`.
