This page describes provider-facing verification and feedback APIs.

## Provider auth

```http
# Preferred
X-Clawb-Api-Key: ck_live_...

# Alternative
Authorization: Bearer ck_live_...
```

## POST `/v1/verify`

Online identity verification for signed agent requests.

### Canonical format

```text
METHOD\nPATH\nTIMESTAMP_MS\nNONCE\nBODY_SHA256
```

### Request

```json
{
  "agent_id": "agt_...",
  "method": "POST",
  "path": "/v1/refunds",
  "timestamp_ms": 1740137855000,
  "nonce": "2f8d8b19-5e0a-4f8b-b7d4-6dc15b1fe201",
  "body_sha256": "3adfd3eb02f15d4f4b5a9f5b2d18f8d1b6d8a7eac03f4b7a56ec8f8c2f2ff321",
  "signature_b64": "<base64>"
}
```

### curl example

```bash
curl -sS -X POST "https://api.clawb.ai/api/v1/verify" \
  -H "Content-Type: application/json" \
  -H "X-Clawb-Api-Key: ck_live_replace_me" \
  -d '{
    "agent_id": "agt_replace_me",
    "method": "POST",
    "path": "/v1/refunds",
    "timestamp_ms": 1740137855000,
    "nonce": "2f8d8b19-5e0a-4f8b-b7d4-6dc15b1fe201",
    "body_sha256": "3adfd3eb02f15d4f4b5a9f5b2d18f8d1b6d8a7eac03f4b7a56ec8f8c2f2ff321",
    "signature_b64": "<base64-signature>"
  }'
```

### Response

```json
{
  "valid": true,
  "agent_id": "agt_...",
  "verification_tier": "attested",
  "risk_tier": "low",
  "revoked": false,
  "disclosure": {"disclosed": {}}
}
```

### Common failures

- `401` missing or invalid provider key
- `429` rate limited
- `200` with `valid=false` for signature failures

## POST `/v1/reputation/feedback`

Provider feedback with required HMAC signature headers.

### Required headers

- `X-Clawb-Feedback-Timestamp`
- `X-Clawb-Feedback-Nonce`
- `X-Clawb-Feedback-Signature`

### Signature message

```text
{timestamp_ms}\n{nonce}\n{sha256(body)}
```

### SDK example (recommended)

```python
from clawb_agent_sdk import ClawbClient, WorkspaceControlPlane

client = ClawbClient(base_url="https://api.clawb.ai/api")
provider = WorkspaceControlPlane(client=client, api_key="ck_live_...")

# SDK computes timestamp/nonce/signature headers automatically.
provider.reputation_feedback(
    agent_id="agt_01...",
    verdict="bad",
    evidence={"reason": "abuse_suspected"},
)
```

### curl example

```bash
curl -sS -X POST "https://api.clawb.ai/api/v1/reputation/feedback" \
  -H "Content-Type: application/json" \
  -H "X-Clawb-Api-Key: ck_live_replace_me" \
  -H "X-Clawb-Feedback-Timestamp: 1740137855000" \
  -H "X-Clawb-Feedback-Nonce: n_123" \
  -H "X-Clawb-Feedback-Signature: <base64-hmac>" \
  -d '{
    "agent_id": "agt_replace_me",
    "verdict": "bad",
    "evidence": {"reason": "abuse_suspected"}
  }'
```

### Failure modes

- `401 missing_signature_headers`
- `401 timestamp_out_of_range`
- `401 bad_signature`
- `401 replay_detected`
- `400 invalid_verdict`
- `404 unknown_agent`
