title: Provider integration flow (Verify → Check)
---

This page is for API providers and relying services.

It describes the request-time and control-plane integration paths in Clawb’s agent control plane.

At request time, answer two questions:

1. Is this request really from the claimed agent?
2. Is this agent allowed to perform this action now?

## Auth quick reference

```http
# Preferred
X-Clawb-Api-Key: ck_live_...

# Alternative
Authorization: Bearer ck_live_...
```

## Request-time flow

### Step 1: verify identity

- Option A (recommended): local Ed25519 verification
- Option B: online verification with `POST /v1/verify`

### Step 2: enforce policy

Call `POST /v1/check` with `agent_id`, `policy_id`, `action`, and optional context.

Possible decisions:

- `allow`
- `challenge`
- `deny`

## Control-plane flow (new)

In addition to request-time verify/check, providers now run a control plane.

### Agent inventory mapping

- `POST /v1/provider/agents/upsert`
- `GET /v1/provider/agents`

### Audit query and export

- `GET /v1/provider/audit/events`
- `POST /v1/provider/audit/export`

### Short-lived credentials

- `POST /v1/identity/credentials/mint`
- `POST /v1/identity/credentials/revoke`
- `POST /v1/identity/credentials/revoke-by-agent`

### Incident controls

- `POST /v1/identity/kill-switch/minting`
- `POST /v1/identity/kill-switch/revoke-all`
- `GET /v1/identity/kill-switch/status`

### Reputation feedback

- `POST /v1/reputation/feedback` (signed feedback headers)

## Recommended architecture

1. Edge layer verifies inbound agent signatures.
2. Decision layer calls `/v1/check`.
3. Control-plane jobs sync provider inventory and export audits.
4. Sensitive follow-on actions use short-lived minted credentials.
5. Security operations can pause minting and revoke all credentials quickly.

## Python SDK starter

```python
from clawb_agent_sdk import ClawbClient, ApiProvider

client = ClawbClient(base_url="https://api.clawb.ai/api")
provider = ApiProvider(client=client, api_key="ck_live_...")

# request-time
provider.verify(...)
provider.check(...)

# control-plane
provider.provider_agents_upsert(...)
provider.provider_audit_events(limit=50)
provider.identity_credentials_mint(agent_id="agt_01...", ttl_seconds=300)
```
